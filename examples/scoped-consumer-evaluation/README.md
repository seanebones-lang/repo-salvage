# Consumer adaptation from scoped supporting evidence

One fresh, tool-free native Codex session produced an English integer formatter
from the exact focused Humanize response used in the previous scoped-context epoch.
Its unchanged first generated module passed nine acceptance tests and 1,500 seeded
Decimal-reference comparisons in a separate isolated Python workspace.

The requirements and tests were written and sealed before generation. The contract
is deliberately narrower than Humanize: integers only, English names, fixed 0–6
decimal places and exact half-even rounding through the exercised `10**200` range.
No float/string coercion, arbitrary format strings, localization or third-party
imports are included. These are authored requirements on one familiar source
family, not a discovery trial, general transfer score or training holdout claim.

## Frozen replay

`seal.json` binds the initial inputs, test program, notice, prompt, schema and trusted
host/client code before model use. `input-archive.json` was assembled afterward;
every archived byte matched that pre-run seal. It keeps future application-client
edits from invalidating a historical replay. Archive programs are checked as data
and never imported or executed by the replay loader.

`results-seal.json` binds the native result, review, execution record, input archive,
exact generated module and isolation driver back to the initial seal. The completed
operator entry point refuses both implicit account use and result overwrite. It
must not be refrozen or rerun in place. A later change needs a new epoch; earlier
model failures, controls and seals remain unchanged.

```sh
node --test tests/scoped-consumer-evaluation.test.mjs
npm run test:integer
```

These commands replay offline with no model calls or source-network requests.
The adaptation is available in [integer-word-consumer](../integer-word-consumer/README.md).
Its exact arithmetic, type policy and English-only output are explicit adaptations,
not inferred behavior of missing Humanize localization code. Public deployment,
general recall and independent external-user adoption remain separate evidence.
